# I hate Ads

선택한 Android 앱의 네트워크 연결을 차단하는 앱입니다.

## 주요 기능

- 사용자가 설치한 앱을 여러 개 선택
- 선택한 앱의 Wi-Fi 및 모바일 데이터 연결 차단
- 차단 중 앱 추가·제거 및 차단 상태 확인
- 선택 목록과 차단 설정 저장

Android `VpnService`를 사용하므로 처음 차단을 시작할 때 VPN 연결 권한이 필요합니다. 다른 VPN과 동시에 사용할 수 없습니다.

## 실행 방법

1. Android Studio에서 이 프로젝트를 엽니다.
2. Android 10(API 29) 이상 기기에 앱을 설치하고 실행합니다.
3. 차단할 앱을 선택하고 **차단 시작**을 누른 뒤 VPN 권한을 허용합니다.
4. 중단하려면 **차단 해제**를 누릅니다.

자세한 동작과 요구사항은 [스펙 문서](docs/spec.md)를 참고하세요.
