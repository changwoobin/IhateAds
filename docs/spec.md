# 앱별 네트워크 차단 앱 스펙

## 1. 목적

사용자가 설치된 앱을 여러 개 선택하고 차단을 시작하면, 선택한 앱의 네트워크 사용을 막는다. 앱을 최근 앱 화면에서 스와이프해 닫으면 차단을 해제한다. 그 전에 차단 중이었다면 앱을 다시 열 때 저장된 선택 목록에 차단을 다시 적용한다. 사용자가 직접 차단을 해제했다면 다음 실행에도 해제 상태를 유지한다.

## 2. 핵심 사용자 흐름

1. 사용자가 앱을 열고 설치된 앱 목록을 확인한다.
2. 네트워크를 차단할 앱을 하나 이상 선택한다.
3. 사용자가 **차단 시작**을 누른다.
4. 앱이 Android의 VPN 연결 동의를 요청한다. 사용자가 동의하면 선택한 앱의 네트워크 차단을 시작한다.
5. 사용자는 차단 중인 앱과 차단 상태를 확인할 수 있다.
6. 사용자가 **차단 해제**를 누르면 네트워크 차단을 중단한다. 다시 앱을 열어도 직접 **차단 시작**을 누르기 전까지 해제 상태를 유지한다.
7. 차단 중 앱을 최근 앱 화면에서 스와이프해 닫으면 차단을 중단한다. 다시 열면 선택 목록을 복원하고 차단을 재개한다.

## 3. 기능 요구사항

### 앱 선택

- 사용자가 설치한 앱만 목록에 표시하고, 각 앱의 이름과 아이콘을 보여준다. 시스템 앱은 표시하지 않는다.
- 사용자는 여러 앱을 동시에 선택하거나 선택을 해제할 수 있다.
- 선택한 앱이 없으면 차단을 시작할 수 없다.
- 차단 중에도 앱을 추가하거나 제거할 수 있으며 변경 사항은 현재 차단에 적용한다.
- 마지막으로 선택한 앱 목록을 저장하고, 앱을 다시 열었을 때 복원한다.

### 네트워크 차단

- 선택한 앱의 Wi-Fi와 모바일 데이터 트래픽을 차단한다.
- 선택하지 않은 앱의 네트워크 사용은 영향을 받지 않아야 한다.
- 차단은 화면을 떠나거나 앱 UI가 백그라운드로 이동해도 유지한다.
- 앱을 최근 앱 화면에서 스와이프해 닫으면 차단을 중단한다.
- 사용자가 앱 안에서 **차단 해제**를 누르면 즉시 차단을 중단한다.
- 직접 차단을 해제한 상태는 저장한다. 이후 앱을 다시 열어도 자동으로 차단하지 않는다.
- 기기를 재부팅한 뒤에는 차단을 자동으로 시작하지 않는다. 재부팅 전 차단 중이었다면 사용자가 앱을 열 때 저장된 앱 목록을 대상으로 차단을 다시 시작한다.
- 차단이 실제로 동작하지 않는 상태에서는 UI에 차단 중이라고 표시하지 않는다.

### 상태 및 권한

- UI에 `차단 안 함`, `권한 요청 중`, `차단 중`, `오류` 상태를 구분해 표시한다.
- VPN 권한을 거부하거나 연결에 실패하면 차단을 시작하지 않고 원인을 알린다.
- Android가 VPN 연결을 종료한 경우 상태를 갱신하고 사용자에게 알린다.
- 차단 중에는 Android가 요구하는 지속 알림을 표시한다.

## 4. 구현 방향

- Android `VpnService`를 사용한다. `VpnService.Builder.addAllowedApplication()`에 선택한 앱을 등록하여 해당 앱의 트래픽만 VPN 인터페이스로 보낸다.
- VPN 인터페이스로 들어온 트래픽은 외부 네트워크로 전달하지 않아 차단한다. IPv4와 IPv6를 모두 고려한다.
- `addDisallowedApplication()`은 앱을 VPN에서 제외해 일반 네트워크를 사용하게 하므로 차단 대상 설정에 사용하지 않는다.
- Android에서는 동시에 활성화할 수 있는 VPN에 제약이 있다. 다른 VPN이 활성화되어 차단을 시작할 수 없는 경우 오류를 안내한다.
- 최근 앱에서 스와이프해 닫는 이벤트를 서비스에서 처리하여 VPN 연결을 종료한다. 제조사별 최근 앱 동작 차이는 실제 기기에서 검증한다.
- 현재 프로젝트의 최소 SDK는 API 29이다.
- 구현 시 파일 수와 클래스 수를 불필요하게 늘리지 않고, 화면과 차단 서비스 중심의 단순한 구조를 유지한다.

## 5. UI 요구사항

- 한 화면에서 앱 선택, 차단 상태 확인, 차단 시작·해제를 할 수 있게 구성한다.
- 선택된 앱과 선택되지 않은 앱을 명확히 구분한다.
- 차단 중 앱을 추가하거나 제거하면 적용 상태가 화면에 바로 반영된다.
- 색상은 기본 색과 강조 색 위주로 제한하고, 간결한 화면을 유지한다.

## 6. 첫 버전에서 제외

- 앱별 시간표, 사용량 통계, 도메인별 차단
- 기기 재부팅 후 차단 자동 재개
- 다른 VPN과 동시 사용

## 7. 완료 기준

- 사용자가 앱 여러 개를 선택해 차단을 시작하고 직접 해제할 수 있다.
- 차단 중 선택한 앱은 Wi-Fi와 모바일 데이터에서 네트워크에 접속하지 못한다.
- 선택하지 않은 앱은 정상적으로 네트워크에 접속한다.
- 다른 앱으로 이동해도 차단이 유지되고, 최근 앱에서 스와이프해 닫으면 차단이 종료된다.
- 차단 중 앱을 추가·제거하면 해당 앱의 네트워크 차단 상태가 바뀐다.
- 재부팅 뒤에는 자동으로 차단하지 않는다. 재부팅 전 차단 중이었다면 앱을 열 때 저장된 목록에 차단을 다시 적용한다.
- 사용자가 직접 차단을 해제했다면 앱을 다시 열어도 해제 상태를 유지한다.
- VPN 권한 거부, 연결 실패, 시스템에 의한 VPN 종료가 UI 상태에 반영된다.
